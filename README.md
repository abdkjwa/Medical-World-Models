# Medical-World-Models

A curated collection of medical world model papers, code, datasets, and benchmarks.

---

# 能力等级

基于 [Qazi 等人（2025）](https://arxiv.org/abs/2511.16333) 提出的能力框架：

| **级别** | **名称** | **能力** | **示例** |
|-|-|-|-|
| L1 | 时间预测 | 预测未来状态 | 预测未来的医学影像 |
| L2 | 动作条件化 | 基于动作的预测 | 根据处理/探头的移动进行预测 |
| L3 | 反事实推广 | 反事实推理，决策支持 | “如果我们用药物A代替药物B呢？” |
| L4 | 规划与控制 | 闭环规划，实时控制 | 自主手术规划 |

# 医学世界模型五大技术路线

| **技术路线** | **核心思想** | **代表性工作** |
|-|-|-|
| **生成式观测派** | 在影像观测空间生成治疗后的三维医学影像，模拟病灶演化 | MeWM、DiffTumor |
| **潜状态动力学派** | 在患者隐状态空间推演病程轨迹，服务预后评估与治疗方案筛选 | EHRWorld、CLARITY、基于RSSM/JEPA的患者轨迹模型 |
| **生理机理约束派** | 以已知生理、药代动力学方程为骨架，用临床数据校准参数 | 虚拟生理人、器官级数字孪生、PINN医学模型 |
| **因果治疗效应派** | 聚焦干预 - 结局的因果关系估计，消除临床混杂偏倚，估计干预本身带来的反事实疗效差异 | 因果生存分析模型、EHR反事实治疗效应系列 |
| **手术与具身交互派** | 建模器械与软组织的交互动力学，支撑术中交互仿真与机器人控制 | WM-Grasp、外科机器人交互仿真模型 |
